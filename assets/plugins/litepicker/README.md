# Litepicker 2.0.12

Date-range picker used by the Apply for Leave page (`modules/leave/apply.php`).

- Source: npm `litepicker@2.0.12`, files `dist/nocss/litepicker.js` and
  `dist/css/litepicker.css`, copied unchanged. The no-CSS build is used so the
  stylesheet is a plain file the RI theme can override, not one injected at runtime.
- Licence: MIT, see `LICENSE.md`.
- Upstream (github.com/wakirin/Litepicker) is archived and receives no fixes. The
  picker is used on one page, so replacing it means changing that page only.
